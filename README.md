# Cube3D

## Overview
A graphical rendering project inspired by the legendary Wolfenstein 3D.
Cub3D is a first-person perspective maze game built using the mathematical concepts of Raycasting,
written entirely in C.

## Tech Stack
* **Language:** C
* **Graphics Library:** miniLibX (École 42 internal graphics library)
* **Concepts:** Raycasting, Mathematics (Trigonometry, Vectors), Parsing, Texture Mapping, Event Handling.

## Features
* Custom map parsing and validation.
* Smooth first-person movement and camera rotation.
* Texture mapping for walls and sprite rendering.
* Collision detection.
